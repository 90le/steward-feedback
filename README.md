# Steward Feedback

这里收集 Octo 的产品问题、Bug 和功能需求，并保存 PRD、评审与修订记录。

可以在已接入的 Octo 群或私聊向小丘反馈，也可以直接创建 Issue。小丘会先澄清场景、查询已有事项，再返回可追踪的记录。

- **小丘**：产品问答、反馈收集、查重和状态回报。
- **小助**：撰写与修订 PRD。
- **小衡**：独立评审需求与验收标准。

功能需求会进入“起草 → 评审 → 修订 → PRD 就绪”流程。PRD 通过表示需求文档已准备好，不表示功能已经开发、修复或发布。

## 反馈内容

Bug 请说明使用场景、预期结果、实际结果，以及可提供的复现条件。功能需求请说明目标用户、希望完成的事情和当前困难。

本仓库公开可见；只提交需要公开协作的业务事实，不提交凭证、私聊原文或个人敏感信息。

## 标签

- 类型：`type/bug`、`type/feature`。
- 优先级：`priority/p1`、`priority/p2`、`priority/p3`，默认 `p2`。
- 流程：`status/triage`、`status/needs-info`、`status/prd-drafting`、`status/prd-review`、`status/prd-revise`、`status/prd-ready`。

GitHub 的打开/关闭状态及关闭原因独立保留。自动化只在发生有意义的变化时回报；没有变化时保持安静。
