# Octo 小码（runtimeId: implementation）

PRD v2 · 候选 r1

# 群置顶到期自动取消 · 演示原型

演示 PRD「群置顶消息到期自动取消置顶」v2 的用户结果和验收点。**这是原型，不是真实 Octo 功能**：数据在内存里、模拟身份通过 `X-User-Id` 请求头切换，用户系统 / 群聊 / 权限均为演示实现。

## 运行方式

需要 Node 24（已在沙箱内），只用内置模块，不需要 `npm install`。

```bash
node server.mjs                 # 默认端口 3000
PORT=8080 node server.mjs       # 自定义端口
```

打开 <http://127.0.0.1:3000> 即可。`server.mjs` 通过 `import.meta.url` 相对定位 `index.html`，可以从任意工作目录（例如 `/tmp`）启动。

前端也支持直接双击 `index.html` 作为纯静态原型使用；此时页面头部会显示「本地模拟」，所有数据在浏览器内存里。后端在返回首页时会给 `<html>` 加上 `data-api="1"`，前端探测到该标记才会走 `/api/...` 联调，页面头部显示「联调模式」。

## 模拟身份

页面右上角切换。后端也用同一份表，只信任 `X-User-Id` 请求头：

| ID | 名称 | 置顶权限 |
| --- | --- | --- |
| `admin` | Alice | ✔ |
| `admin2` | Bob | ✔ |
| `member` | Carol | ✘（无入口，同时后端返回 403） |

未知或缺失 `X-User-Id`：后端返回 401。

## 接口一览

统一 JSON，失败响应格式 `{ "error": { "code": "...", "message": "..." } }`。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET  | `/`                              | 返回前端 HTML，注入 `data-api="1"` |
| GET  | `/api/health`                    | 健康检查；返回消息与置顶数量 |
| GET  | `/api/messages`                  | 列出全部消息（每次先扫一次到期） |
| POST | `/api/messages`                  | 新增消息；可选 `pin`、`expireAt` |
| POST | `/api/messages/:id/pin`          | 置顶/取消置顶：`{ pin: true|false }` |
| PUT  | `/api/messages/:id/expire`       | 修改到期时间：`{ expireAt: number|null }`（毫秒时间戳；`null` 表示取消到期，保留置顶）|

### 关键错误码

- `unauthenticated` (401)：缺少或未知的 `X-User-Id`
- `forbidden` (403)：当前身份无置顶权限
- `not_found` (404)：消息不存在
- `not_pinned` (409)：对未置顶的消息设置到期
- `invalid_expire` (400)：到期时间格式非法或不晚于当前时间
- `invalid_text` (400)：新消息内容为空

## 到期行为

- 后端有一个每秒扫描的定时器，另外每次收到 `/api/**` 请求也会先扫一次；到期后**只解除 `pinned`，清空 `expireAt`**，不删除消息、不生成任何系统消息或提醒。
- 未设置到期时间的置顶不会因为别的置顶到期而受影响。
- 校验失败时（时间不晚于当前、无权限、消息不存在等）不改动原状态；前端保持原样并提示失败。

## 与 PRD 验收点对照

| 验收点 | 演示位置 |
| --- | --- |
| 设置到期时不填=长期置顶 | 发送区不填「到期时间」直接发送并勾选置顶 |
| 已置顶消息补设到期 | 消息卡片「设置到期」按钮 |
| 到期不晚于当前=不生效并可感知 | 弹窗中选一个已过的时间，收到红色失败 Toast |
| 到期前修改/取消到期 | 消息卡片「修改到期」/「取消到期」 |
| 无权限身份看不到入口 | 切到 Carol，操作按钮消失；即便手动调后端也返回 403 |
| 到期后静默取消置顶 | 观察演示消息 #3（默认到期在 1 分钟后），到点后自动滑落且无提示 |
| 原消息保留不变 | 到期后消息仍在列表中、内容一致 |
| 保存失败保留原状态 | 无权限身份或非法时间时，前端不改动本地状态 |

## 边界与非目标

- 后端仅在内存维护数据，服务重启数据回到初始集合。
- 无外部资源加载、无 iframe、无 cookie 读取、无外链跳转。
- 不接入真实用户系统 / 真实群聊 / 真实置顶存储；PRD 的开放问题（时区精度、跨群顺序、审计追溯等）在原型中未实现，等人类产品负责人决策。
- 不发布、不推送、不写宿主文件。
