## 产品概览

Steward 是运行在 OpenClaw 中的流程程序，组织五个 Agent 处理 Octo 的产品问题与需求。用户自然提问，小丘读取源码、澄清问题、比较已有事项；有效反馈进入公开需求池。小助写 PRD，小衡独立评审并要求修订。PRD 通过后，程序自动安排小码开发演示、小检实际测试，再由小衡复核，小丘回到原会话报告结果。

**Agent 自主决定怎样调查和完成当前任务；程序保存事实，检查进入下一阶段的必要条件。** 模型可以多轮搜索、追踪配置和调用关系、续读较早评论、调整判断、自然组织语言。仓库、凭证、收件人、角色和完成状态由程序核对，不能只凭一句“已经完成”变更。

OpenClaw 提供模型、会话、工具和沙箱；Steward 插件提供本项目的调度、状态与外部操作；五个 Agent 承担支持、产品、评审、开发和测试。Worker 是插件内的程序，不是第六个 Bot。小测是配置放行的测试提问者，也不属于交付团队。

## 用两次真实修订解释价值

### #9：独立评审改变了需求范围

在[置顶消息自动失效](https://github.com/90le/steward-feedback/issues/9)的初稿中，小助未经确认排除了批量管理。小衡[指出缺少用户依据](https://github.com/90le/steward-feedback/issues/9#issuecomment-5559283769)，v2 将这部分改为开放问题。随后流程自动接续开发、测试和复核，形成[最终演示交付](https://github.com/90le/steward-feedback/issues/9#issuecomment-5559448144)。

这说明独立评审的价值在于提出有依据的不同意见。仅增加一个角色并让它输出“通过”，不足以证明协作质量。

### #10：接口测试通过后，实际页面仍暴露问题

[提醒稍后处理](https://github.com/90le/steward-feedback/issues/10)最初通过 HTTP 检查，但建设任务操作浏览器时发现默认时间请求失败，原消息入口只显示提示；后续还发现刷新和跨页状态不同步。这些[具体反馈](https://github.com/90le/steward-feedback/issues/10#issuecomment-5559561466)进入原 Issue，推动版本修订，随后到 v4。追加慢操作检查又发现编辑草稿被自动刷新覆盖；v5 修好这点后，后端请求头和短时快捷项仍有缺口，最后沿原流程完成[PRD v6 演示](https://github.com/90le/steward-feedback/issues/10#issuecomment-5562039070)。

v6 读取了 v5 的三个正式源文件作增量参考，原件与署名保留。小检独立 HTTP 7 项、建设任务可信后端 30 项与静态 25 项分别通过。小检负责的独立 HTTP 测试与建设任务追加的浏览器检查分别记载。测试通过必须说明是哪种测试、哪个版本、哪些实际行为。

## 技术主线：四个必要关口

![身份、证据、评审与外部效果的关口](diagrams/gates.svg)

| 关口 | 程序核对 | Agent 仍需完成 |
| --- | --- | --- |
| 谁可以提出什么 | 真实来源、原生 UID 提及、身份准入、职责 | 判断相关性，理解用户诉求 |
| 根据哪份资料 | 固定源码和知识版本、读取记录、查询完整性 | 调查调用关系与例外，比较语义重复 |
| 哪版可以继续 | 作者与评审分离、PRD 版本、冻结候选、实际复跑 | 写清需求、提出具体意见、开发和测试 |
| 操作是否真的发生 | 固定目标、持久意图、去重、远端对账、平台消息读回 | 汇总结果、准确解释限制与未决问题 |

路径和行号正确只证明证据存在，不证明结论切题；程序门控与语义审核要分别验收。

## 历史取舍

V1 已积累角色文档、知识导航、Hook、扫描脚本和真实协作。ATE 与 协作治理参考项目 资料在这一阶段就曾用于参考，保留了职责、方法和交接方面的思路，没有整体安装另一套权威配置。

V2 有实质控制面和适配器实现，也引入了更多概念与运行身份；部分工具、角色、沙箱声明和消息接线尚未在同一条业务链验证。当前 MVP 聚焦一个 Gateway、一个业务插件、一份业务 SQLite，先完成三角色闭环，再扩到五角色演示交付。已有代码、备份、去重、来源和知识成果继续使用。

完整历史、失败与取舍见[图文介绍第 3–4 章](https://90le.github.io/steward-feedback/#evolution)。历史版本的能力不能套用为当前事实，也不应把它们贬成没有实现的设想。
