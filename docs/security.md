# 安全设计与验证范围

当前实际版本为 mvp-052，已完成记录范围内的修复与复测；原定 20+ 真实凭证对抗和新版真实 DM 验收未完成，见文末边界。本项目让 Agent 获得调查和交付所需资料，同时限制资源与外部操作。模型的合作语气、内部角色名、文本中的管理员声明，都不能成为新的权限来源。

## Bot 消息出口保护

出口保护同时检查直接回复、异步通知、嵌套引用及通用发送/编辑路径，在入队与实际发出前核验敏感内容。命中后重建安全答复或拒绝发送，保持原生提及、来源与回执对应；被保护拦截不计为原业务成功，也不重试敏感原文。完整说明见[Bot 消息出口敏感信息保护](outbound-protection.md)，其中分开列出实现、历史四类真实出口探针与仍未覆盖的范围。

这些问题的隔离复现使用没有生产效力的合成测试标记、模拟接口或本地回环目标。不能据此宣称曾在真实群或公开仓库泄露真实凭证。

## 提示构建之前要有真实来源

曾出现配置已经允许任务，而小码仍拒绝的情况。实际 c04 提示先构建，原运行绑定晚 35 毫秒，模型首轮读到未绑定来源。mvp-049 从确已落库、仍持租约的本次异步入站作用域提前绑定；修复后 c06 的绑定早于提示 1 毫秒，相同输入与同一会话实际执行了命令。没有修改名单或用用户正文声明授权。

后续独立检查又发现 Space DM 的原生会话前缀问题，mvp-050 按实际 Octo 规则严格匹配；错前缀、同会话异用户、跨账户、过期回调和后台权限分别验证。群现场成功仍不代替受好友关系阻塞的真实 DM。

## 原生工具与宿主程序

小码、小检的命令在原生 Docker 中执行，采用非 root、只读根目录、关闭网络、受限资源。源码、设置和冻结候选只读；各角色产物根可写。没有要求的后端时拒绝执行，不退回宿主。小丘、小助、小衡保持受限读取与业务工具，没有因扩员统一开放命令行。

当前产物目录按角色共享。会话隔离不等于同角色文件互相保密，不能宣传成任务级或多租户隔离。原生会话历史、凭证、宿主配置和 Docker socket 不挂入 Agent 容器。

Steward 的 Hook 只控制纳管业务工具；原生 read / exec / process 依赖 OpenClaw 的实际工具和沙箱配置。宿主插件不自动受 Agent 容器限制，固定凭证、目标、路径和来源检查仍需独立保留。

## 内容检测的有限覆盖

在确切敏感值检查之外，已补充完整 Base64 / Base64URL / 十六进制形式、有界 ASCII 百分号解码，以及高区分度不透明值的至少 24 字符连续长片段。JWT 的公共头部可能造成误报，长片段规则不用于它，完整值与其编码仍受检。

当前没有声称覆盖短片段反复拼接、任意分片、多重编码、在编码前加入任意包裹、所有媒体和未知凭证。防线首先是让模型与工作路径拿不到秘密，出口匹配只能增加保护，不能替代资源隔离。被拦截的候选不计为原业务成功。

## 生成预览与原始代码

可信外壳把原始 HTML 放进只允许脚本的隔离 iframe。父页面限制框架导航；子页面在原始内容之前建立策略。生成页面不拥有顶层导航、弹窗、原生表单导航、下载或同源父页面权限。现有案例保留输入控件、按钮与 JavaScript 交互；当前不支持持久 localStorage。

静态模式只操作页面演示数据。后端模式通过随交付提供的临时可信预览服务连接独立启动的演示后端。桥核对固定窗口及来源，只接受限定方法与路径的 JSON API 请求，限制大小、超时、并发和频率，不转发 Cookie、身份凭证或任意网址。生成后端不能改写可信父页面的策略。

迁移将原始文件保存在 Pages 发布目录之外的源码区，旧入口显示可信迁移说明，新入口使用包装版本。实际作者、原始内容摘要、PRD、测试与旧回执均保留；包装变更不能冒充重新开发。本轮六个旧入口已完成迁移。原任务语义保留，仅例行扫描观察字段更新；当前 #9 v2 / #10 v6 入口见[交付记录](delivery.md)。

## 连续对话验证

初段在真实 Octo 会话中持续提问并观察角色、工具与最终回复。已核对的 13 轮当时未观察到真实凭证匹配；一次路径显示保护和一次回复恢复故障分别记载，不能算作凭证成功拦截。

用于实施测试的开发任务平台随后因安全内容检查中断了任务；这不是 Steward 的防护拦截结果。此后停止任何真实凭证提取尝试，只使用自建合成标记和非敏感文件验证角色边界、连续上下文与普通能力恢复。暂停前额外发出的一轮仅核对终态，不对其正文作真实凭证检测结论。初段共发送 14 条、核对 13 条输出；后续 12 条合成中小码三条没有执行文件读取，不能算通过。5 条普通群控制为 3 完成、2 次初始拒绝保留。五个 Bot 私聊预检全部 not_friend，发送 0，运行 0。各轮次与版本详见交付记录，不混算成同一版本的全部真实密钥测试。

## 仍需保留的限制

没有观察到泄露是有范围的结果。宿主失陷、未知秘密、任意多重编码、资源耗尽、所有浏览器与多租户文件保密均不能从这些样本推定安全。浏览器隔离检查也不能替代语义审核、原始业务测试或真实外部回执。
